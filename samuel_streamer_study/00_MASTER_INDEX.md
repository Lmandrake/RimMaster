# Mr Samuel Streamer’s RimWorld Steam Workshop Collections

**Compiled:** 2 August 2026  
**Creator:** [Mr Samuel Streamer on Steam](https://steamcommunity.com/id/MrSamuelStreamer/)  
**Canonical collection index:** [All RimWorld Workshop collections](https://steamcommunity.com/id/MrSamuelStreamer/myworkshopfiles/?appid=294100&section=collections)

## Executive summary

Samuel’s current Steam Workshop index contains **48 RimWorld collections**. They fall into three practical groups:

1. **Current or comparatively recent themed packs**, principally for RimWorld 1.6 or late 1.5-era playthroughs. These usually include an installation guide, load order, configuration files, and often a starting save.
2. **Utility/foundation collections**, such as Bare Essentials, Graphics & UI Upgrade, and the 1.6 Foundation Pack.
3. **Historical collections**, especially the explicitly unsupported 1.2 and 1.3 packs. Samuel deliberately removed their load orders and starting saves to discourage people from loading obsolete configurations into current RimWorld.

The **Workshop collection page is also the installation-and-download page** for nearly every pack. Open the collection link and look for:

- `2: Necessary Files`
- `3: Installation Guide`
- Google Drive links for the load order, configs, starting save, and sometimes a complete backup folder
- A linked first episode or series introduction on YouTube

Steam sometimes displays an “item removed” or “incompatible” banner on directly linked collection pages. The collections remain listed in Samuel’s Workshop index, but availability and visibility can change.

# Standard installation method

Samuel repeats substantially the same procedure across his recent collections.

## Recommended: RimSort

1. Back up any saves or configs you care about.
2. Fully clear the old installation rather than merely unsubscribing:
   - `...\Steam\steamapps\common\RimWorld\Mods`
   - `...\Steam\steamapps\workshop\content\294100`
   - `%AppData%\..\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios`
3. Launch RimWorld once and restore basic personal settings.
4. Subscribe to all items in the chosen Workshop collection.
5. Open **RimSort**, press **Sort**, and save the resulting order.
6. Follow the pack’s `Configs` instructions.
7. Copy any supplied save into the `Saves` folder.
8. Expect a very long first load with 300–500+ mods.

Samuel now generally recommends RimSort’s own sorting function rather than hand-maintaining a fixed order. Older packs instead provide RimPy and/or base-game `.RML` lists.

## Base-game mod manager

Where a `.RML` file is provided:

1. Subscribe to the collection.
2. Download the base-game load-order file.
3. Copy it into:

   `%AppData%\..\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\ModLists`

4. Restart RimWorld.
5. Run the game once before installing the configuration archive.
6. Copy configuration files into:

   `%AppData%\..\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Config`

## DLC warning

Most recent collections state that **all DLC are required**. If some DLC are absent, Samuel advises using RimSort or RimPy to identify and remove DLC-specific dependencies.

Notable stated exceptions:

- **Gravtasm:** all DLC except Anomaly
- **Generations 2:** all DLC except Anomaly

Always re-check the individual page because dependencies can change.

# Practical cautions

- **Do not combine whole Samuel collections casually.** Each is usually a complete 200–500+ mod environment with its own patches, configs, and assumptions.
- **Configs are often essential, not cosmetic.** Samuel repeatedly warns that skipping them can break major systems or make the scenario behave incorrectly.
- **Starting saves may contain hidden setup work.** Scenario parts, world generation, factions, custom pawns, xenotypes, and map edits may not be fully reconstructed by merely loading the same mods.
- **Collection item counts change.** Mods disappear, are replaced, or update to new package IDs.
- **A mod-mismatch warning is not automatically fatal.** Samuel notes that he sometimes removes or substitutes mods after publication, but this does not guarantee every mismatch is harmless.
- **Old packs are references, not supported products.** For 1.2 and 1.3 collections, recreating them requires manually replacing obsolete mods and rebuilding a load order.
- **Back up your own RimWorld profile first.** Samuel’s recommended “full reset” deletes saves, configs, and local data unless you preserve them separately.
