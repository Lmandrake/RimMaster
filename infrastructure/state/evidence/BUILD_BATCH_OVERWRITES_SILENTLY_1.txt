WHAT THE ITEM ASKED FOR                          WHAT THE CODE DOES
---------------------------------------------    ------------------------------------
"refuse the op (default) or report it in a        BOTH. displaced[] always; the refusal
 displaced[] array naming what was destroyed"     is opt-in via refuseIfDisplaces.

"placed counts spawn attempts, not survivors"     `survived` is counted AFTER every op
                                                  (`!t.Destroyed`), with `lostToLaterOps`
                                                  = placed - survived as its own field.

The mechanism, and it is the right one — it PREDICTS the destruction rather than noticing
it afterwards:

    if (GenSpawn.SpawningWipes(td, other.def) && !doomed.Contains(other))
        doomed.Add(other);
    ...
    displaced.Add(new { op, destroyed = d.def.defName, x, z,
                        placedByThisBatch = spawnedThings.Contains(d) });

`placedByThisBatch` is the exact case the item measured: the destroyed thing was placed by
an EARLIER op of the same run, so `placed` had already counted it.

refuseIfDisplaces defaults OFF, with the reason in the parameter's own description: a door
legitimately replaces the wall in its cell, so refusing by default would break ordinary
layouts. Turn it on when a generator's output must not eat itself.

The Description now leads with `🔴 READ survived, NOT placed`, and the message field says
so in words whenever lostToLaterOps > 0.
