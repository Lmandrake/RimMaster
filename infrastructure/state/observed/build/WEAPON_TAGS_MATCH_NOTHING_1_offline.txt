================================================================================
THE INSTRUMENT WAS WRONG, AND IT IS THE HEADLINE
================================================================================
weapon_tag_audit.py printed "emptied by the cut: 0" and the ruling in
items/FIFTEEN_TAGLESS_KINDS_RULING_1.md was built on it - "🔑 THE CUT IS NOT THE CAUSE".

That zero was STRUCTURALLY GUARANTEED and never a measurement.

  🔴 Cherry Picker does not DELETE a cut weapon. It NEUTERS it in place.
     AM_PKM, AM_PKP, Gun_Needle, Gun_Scattergun, Flamebow: all still present in the
     dump, all with weaponTags == [] and MarketValue == 0.
     Measured: 183 of 183 cut weapons are present-and-neutered. ZERO were deleted.

  ⇒ audit() built its tag index from the dump's weaponTags. A neutered weapon
    contributes NO tag, so a tag whose every carrier was cut never enters the index
    at all - it cannot be counted as "emptied", it is simply absent. The `cut` filter
    could only ever fire on a tag that still had a live carrier, which by definition
    is not empty. The counter could not return anything but 0.

  ⇒ ATTRIBUTION REQUIRES THE MOD'S SOURCE XML, which still carries the tag the
    neutered def used to have. That is how the table below was built.

Fixed in this commit: the false line is gone, replaced by the neutered count and an
explicit warning; the mechanism is written into audit() as a comment.
