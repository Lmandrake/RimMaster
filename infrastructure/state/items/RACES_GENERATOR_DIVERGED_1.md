# RACES_GENERATOR_DIVERGED_1 The Star Wars races XML is hand-edited but claims to be generated

## spec

`D:\Luke\dev\Rimworld\src\Jawa\RimMandrake_StarWarsRaces\Defs\PawnKindDefs\RimMandrakePawnKinds.xml`
opens with:

```
GENERATED by src/RimMandrake/Utils/gen_races_mod.py. Do not hand-edit.
```

That is no longer true, and the gap is eight days wide.

| when | what | commit |
|---|---|---|
| 08-15 05:56 | file first generated | `ea504641` |
| 08-15 13:53 | generator gains `initialResistanceRange` (line 912) | `e4d60403` |
| 08-23 01:48 | **hand edit** — robes + hoods | `e479d8ae` |
| 08-23 02:43 | **hand edit** — faction colours, 31 kinds | `9bb5a5bb` |

The generator has not been run since the file was created. So it holds a fix that has
never shipped (see `PAWNKIND_RESISTANCE_UNDEFINED_1`), while the file holds two days of
edits the generator has never heard of.

## Why this is its own item

Both directions are now booby-trapped:

- **Run the generator** → the missing `initialResistanceRange` appears on all 69 kinds,
  and today's robes/hoods and faction colours are silently reverted. The run reports
  success. Nothing warns.
- **Hand-edit again** → widens the divergence and the next person to trust the header
  loses more.

⛔ Do not close `PAWNKIND_RESISTANCE_UNDEFINED_1` by regenerating until this is settled.

## Decide one of three, then do it

1. **Generator wins.** Port the robes/hoods and faction-colour logic into
   `gen_races_mod.py`, regenerate, diff against the current file until the only
   difference is `initialResistanceRange`. Header stays true.
2. **File wins.** Delete the "GENERATED / do not hand-edit" header, retire the
   `write_pawnkinds` path in the generator, and own the XML by hand from here.
   Cheapest, and honest.
3. **Split.** Generator writes a base file; a patch mod carries the hand decisions.
   Most machinery, only worth it if more generated species are coming.

Recommendation is **1** if more species are still to be added, **2** if the roster of 69
is now closed. That is a DECIDE call on whether the species list is finished.

## verify

- The header's claim matches reality: either `python3 src/RimMandrake/Utils/gen_races_mod.py`
  reproduces the committed file byte-for-byte, or the file no longer claims to be generated.
- `grep -c initialResistanceRange` on the file returns 69.

- The other files that generator writes may have diverged the same way. Check every

- Filed by REP from git history plus a read of the generator. Nobody has attempted a
