## spec
🔴 **The player's Jawas spawn in jeans, a t-shirt and a hay sunhat.** Six of six, measured
live on 2026-08-22:

    2x  Apparel_Pants · DV_Apparel_HaySunhat · VAE_Apparel_Tunic · VAE_Handwear_Gloves
    1x  Apparel_BasicShirt · Apparel_Pants · Apparel_Tuque · VAE_Handwear_Gloves
    1x  Apparel_BasicShirt · Apparel_Pants · DV_Apparel_HaySunhat
    1x  Apparel_BasicShirt · Apparel_Pants · DV_Apparel_HaySunhat · VAE_Handwear_Gloves
    1x  Apparel_Pants · DV_Apparel_HaySunhat · VAE_Apparel_Tunic

No hood. No robe. `SCENARIO_SPEC.md:98,121` makes the Jawa robe and hood the starting
apparel, and `faction_equipment_guidance.md` lists this as one of the four cases where
**the apparel IS the pawn**.

## the cause — a matching patch on the wrong def
Two `PawnKindDef`s exist, both `defaultFactionDef: PlayerColony`:

| def | `apparelRequired` | xenotype |
|---|---|---|
| `RimMandrake_Jawa` | ✅ `guy762_Robes_jawa`, `guy762_JawaHood` | — |
| **`RimMandrakeJawa_Kind`** | 🔴 **none**, `apparelTags: ['IndustrialBasic']` | ✅ `MandrakeJawa` 1.0 |

`SpeciesStartingGear_Tuning.xml:108-114` gives the robe and hood to `RimMandrake_Jawa`.
`JawaXenotype_Repoint.xml:45-51` gives the right xenotype to `RimMandrakeJawa_Kind`.
**Neither kind has both**, and the one that spawns is the one without the clothes.

⚠️ This validates clean and logs nothing — the patch *does* match a real def. It is only
visible by looking at a pawn. `validate_patch.py` reported 1 match, 0 errors, correctly.

## the fix, and the thing to settle first
🔴 **First establish which kind the scenario actually uses for starting colonists**, because
that decides the shape of the fix and I could not settle it from the defs alone — both are
`PlayerColony`.

- If **`RimMandrakeJawa_Kind`** is the live one: add the same `apparelRequired` block to it.
  ⚠️ Do it as a PATCH — `RimMandrakePawnKinds.xml` is generated by
  `src/RimMandrake/Utils/gen_races_mod.py` and a hand edit dies at the next run. That is
  already why `JawaXenotype_Repoint.xml` exists; extend that file rather than adding another.
- If **`RimMandrake_Jawa`** is the live one: then criterion (c) of `B58` was aimed at the
  wrong def and the xenotype repoint is on the wrong kind instead — check which xenotype
  `RimMandrake_Jawa` rolls before assuming it is fine.
- If **both** can spawn: both need both.

## while you are in there — the same gap is wider than one kind
