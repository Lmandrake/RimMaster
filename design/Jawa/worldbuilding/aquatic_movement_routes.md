# Aquatic movement — the honest menu, post-Pathfinding-Framework

**The question:** how can 18 sea beasts *move* in a RimWorld 1.6 game when the
sea is `WaterOceanDeep`, which no non-vehicle pawn may enter?

**The two gates (source, not memory):**

| Gate | Where | What it says |
|---|---|---|
| Path cost | `PathGrid.CalculatedCostAt`, `Verse/AI/PathGrid.cs:125` | `Impassable` terrain → 10000 unless `def.flying && terrainDef.forcePassableByFlyingPawns`. `WaterDeep` sets that flag; `WaterOceanDeep` does **not** (`Core/Defs/TerrainDefs/Terrain_Water.xml`). The method is `virtual`; `PathGridDef.workerType` picks the subclass. |
| Reachability | `Region.Allows`, `Verse/Region.cs:284`; `Reachability.cs:283` | Impassable terrain forms `RegionType.ImpassableFreeAirExchange` regions (`RegionTypeUtility.cs:17`), which are not in `Set_Passable`. **One region grid per map, shared by every PathGridDef** (`PathingContext` holds only `map` + `pathGrid`). So even a permissive path grid cannot make a deep-water cell a *destination*: the job system says "unreachable" before the pathfinder runs. |

Everything vanilla gives a "swimmer" (`waterCellCost`, `waterSeeker`,
`swimmingGraphicData`, `moveSpeedFactorByTerrainTag`, `canFishForFood`) tunes
**walkable** water only — `WaterOceanShallow` is `Walkable`, tag `Ocean`, and is
real sea. Nothing installed changes this: the live `ModsConfig.xml` (read
2026-09-02) has no mod that patches deep-water passability for a pawn; Biomes!
Islands is **not on disk** (0 `About.xml` carry `BiomesTeam.BiomesIslands`; Alpha
Animals' `1.6/Mods/BiomesIslands/` submod is gated `IfModActive` on it and never
loads); Biomes! Core's deep-water passability patch ships commented out.
