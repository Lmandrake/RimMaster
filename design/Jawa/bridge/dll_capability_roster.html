Rules I invented — overrule any of them in one line

  • The EASY / MEDIUM / HARD calls are mine. They are judgement about C# effort, not anything RimWorld states. HARD generally means “the engine fights you”, not “long”.
  • The 24 domains are mine too. RimWorld has no such grouping; I split by what a tool would touch, so a capability could defensibly sit in a different box.
  • One row can cover several tools. 63 rows are marked BUILT against 121 shipping jawa/ tools — the roster is capabilities, not a 1:1 tool list.
  • A BUILT row is still cullable, and FLAG is there for “this exists and is not good enough”.
