# World_54

## Charlottes RimWorld

**Map Details:**  
- 275 x 275 map  
- 50% world size  
- Slate, Granite & Limestone  
- Ferralisk Infested Jungle (Alpha Biomes)

---

## Mods Required

- [Alpha Biomes](https://steamcommunity.com/workshop/filedetails/?id=1841354677)

---

## Notes

Remains of Giant Spiders' Exoskeletons. Giant walls of Solidified Web. Large spiders roam the landscape. This biome from the mod Alpha Biomes truly offers one of the most difficult habitats. Best of luck.

---

## Downloads

- **Vanilla Save File:**  
  Drop this file into your vanilla save folder to use it without mods.
- **Map Saver Files:**  
  Place these in the Map Saver folder located in your game files.
